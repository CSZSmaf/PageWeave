# 绘图

通过“插入 → 图形”打开绘图编辑器。点击左侧图形即可加入画布，也可拖入指定位置。图形库提供 18 种形状和三个流程图例，可按名称搜索。

## 图形与公式

拖动图形改变位置，拖动边框控制点调整尺寸。上方圆形手柄用于旋转；右侧可直接输入坐标、宽高、角度、字号和边框粗细，并设置颜色、透明填充与虚线。

双击图形编辑内容。右侧切换“文字 / LaTeX 公式”，输入公式后立即显示预览。工具栏“公式”可插入独立公式，右侧提供分式、根式、求和和矩阵起点。公式采用 KaTeX 支持的 LaTeX 语法，PDF 中使用 LaTeX 排版。

## 连线与自由绘制

- **连接**：从图形连接点拖向另一图形，或使用连接工具依次点击起点与终点。在空白位置拖动可绘制独立箭头。
- **调整**：选中连线后拖动端点，可重新连接到图形或移至空白位置。折线控制点和贝塞尔控制点均可拖动；双击连线增加折点。右侧设置直线、折线、曲线、两端箭头、连接位置、线宽、颜色及标签公式。
- **画笔**：按下并拖动绘制自由路径。完成后可移动、调整大小、简化路径或逐点编辑。
- **多边形**：逐次点击顶点，按 Enter 或双击完成。可设置闭合路径及填充颜色。

## 选择与整理

在空白画布拖动进行框选，Shift+单击增减选择。多选图形后可对齐或均匀分布。图形的置顶、置底按钮调整图形之间的覆盖顺序。

| 操作 | 快捷键 |
| --- | --- |
| 选择 / 连接 / 画笔 / 平移 | V / C / P / H |
| 全选 | Ctrl+A |
| 复制一份 | Ctrl+D |
| 绘图内部复制 / 粘贴 / 剪切 | Ctrl+C / Ctrl+V / Ctrl+X |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y |
| 移动 1 / 10 单位 | 方向键 / Shift+方向键 |
| 等比缩放 / 旋转吸附到 15° | 拖动时按 Shift |
| 临时取消网格吸附 | 拖动时按 Alt |
| 缩放画布 | Ctrl+滚轮，或底部缩放按钮 |

点击“应用”将图形放入正文；双击正文中的图形可再次打开。绘图对象与生成的矢量 TeX 一起保存在 `.tex` 文稿中，自动保存和工程导出沿用文稿操作。旧版流程图可继续打开，编辑后使用新版格式保存。

交互参考：[draw.io 连线与控制点](https://www.drawio.com/docs/manual/connectors/)、[公式排版](https://www.drawio.com/docs/manual/text/math-typesetting/)、[自由绘制](https://www.drawio.com/docs/manual/shapes/freehand-drawing/)。
