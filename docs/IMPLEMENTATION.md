# 页面写作实现

## 连续写作与正式 PDF

WritingPdf 使用 PDF.js 显示 XeLaTeX 生成的真实 PDF。mogao.sty 通过 zref-savepos / abspage 写出区域起止位置、页码和页面尺寸。编译服务读取 aux，换算 PDF 坐标，覆盖正文点击区域。跨页区域为每页生成位置。

FlowEditor 将所有可编辑正文区域连接为单个 Tiptap 文档。sourceId 属性保持 LaTeX 区域归属，Enter、跨段落删除和选择不受区域边界限制。段落、标题、硬换行和公式在同一个编辑状态中；公式由 KaTeX 显示，单击独立公式或双击行内公式进入 MathLive。

Pagination 在不可编辑的离屏副本中测量实际字体行框，按纸张、页边距和手动分页计算间隔，用 ProseMirror Decoration 在行间或段落间显示页边距和纸张间隙。分页不切分正文节点，不写入文档、不进入撤销历史。一个长段落可以跨页。组合输入期间暂缓重分页，结束后再处理；正文缩短或字号、页边距变化会自动回流。

LiveSession 在输入停顿 450 ms 后串行回写，持续输入最长 2 s 回写一次；回写后 850 ms 请求编译。积压修改合并为最近版本，编译仅同时运行一份，旧版本结果不发布。自动编译只更新 PDF 视图，始终保留编辑器实例、选区、光标和历史。保存、导出、工程切换和关闭前先排空待写队列。真实 PDF 与浏览器排版可能有断行差异；导出使用匹配当前源码版本的真实 PDF。

## 源码与事务

Project 保存原始字节、编码、磁盘基线和当前文本。core/writing.ts 只解析明确的写作结构；未知命令保留，禁止区域回写。文本转义 TeX 特殊字符，字体采用固定集合，公式保留数学 LaTeX。

富文本 JSON 只用于编辑过程，持久文件是普通 .tex 与 .sty。格式、标题、公式、分页、图片和表格均用普通宏命令表达，工程可在应用外编译。文字颜色采用可见色板和自定义色；MogaoText 的空参数继承当前字体和字号，单独改颜色不会把标题重置为正文大小。

writeFlow 一次事务更新受影响的区域，跨区域删除可合并正文，编辑器撤销可重新插入被删除的区域 ID；外围源码和区域间注释保留。拒绝重复 ID、已有区域重排以及未经适配的正文。Tiptap 管理连续正文的撤销，TextHistory 保留后端源码事务；页面设置暂不进入正文的撤销栈。

保存先检查外部修改，再写同目录临时文件并替换。保存与编译在首次 await 前冻结数据，期间新输入属于下一版本。UTF-8 BOM 保留，未知编码只读。

## 桌面与编译

Electron 使用窄 IPC、contextIsolation 和 sandbox，关闭 nodeIntegration。禁止新窗口、外部页面导航和网页权限请求；生产 HTML 使用 CSP。

Windows 上关闭窗口后台节流和原生遮挡检测，避免被其他窗口遮挡时自动分页与绘制停住。仅在应用进程内生效，不修改系统或其他应用的设置。

主进程 spawn 调用已有 TeX Live，源码不拼接到 shell。latexmk 使用 -norc，TeX 关闭 shell escape。没有 OS 级进程沙箱和增量编译缓存。

CodeMirror 多文件编辑、主入口选择、日志直接集成到同一应用的“源码”视图，不再载入旧版独立工作台。主入口是页面写作。静态语法解析具有明确子集，不是完整 TeX 解释器。

## 边界

任意模板不能自动转换成可视化写作工程。连续编辑要求主文件正文全部由已适配的 MogaoBlock 构成，区域之间只允许空白或注释；不满足时保留 PDF 和源码视图。DOCX 交换、自定义数学宏适配尚未实现。真实系统中文 IME、长文档交互和跨机器环境需后续验证。

## 图片与表格

FlowImage 是正文中的独立图片节点。Electron nativeImage 解码用户选择的 PNG / JPEG / WebP 并转换为 PNG；新资源先加入内存工程，再和正文一起保存。前端通过窄 IPC 读取工程内图片的数据 URL，不加载外部图片地址。图片宽度和自然尺寸进入源码，正式 PDF 使用 graphicx。新增文件保存检查路径、外部同名文件和实际父目录，不能覆盖已有文件。

表格使用 Tiptap Table / TableRow / TableCell / TableHeader，支持普通单元格、段落和行内公式。页面分页按实际行高插入只读装饰行；这些间隔不进入文稿。表格末尾自动保留正文段落，便于继续输入。正式 PDF 使用 longtable；源码序列化拒绝合并单元格、嵌套和非普通表格结构。当前为等宽列，不能在一个单元格内放独立图片或独立公式，超高单行不能跨页拆分。

mogao-tools.sty 随工程保存，提供可继承的 MogaoText、MogaoImage、MogaoTable、MogaoRow、MogaoCell。若工程已有内容不同的同名样式文件，则拒绝覆盖并保留当前编辑内容。

## 独立公式

FormulaCompiler 复制当前工程到隔离快照，保留前导宏包，替换为 standalone 文档类并仅加入待编辑公式。预览调用与正文编译分离，不修改原始正文或历史。FormulaList 索引独立及行内节点，应用时校验原公式后只替换该节点。MathDialog 可视化输入、按需源码、独立真实 LaTeX 预览并存。

## 统一视图、工具区与字数

写作、PDF、源码共用同一个 LiveSession。源码草稿按文件合并并串行写入；输入期间到达的旧响应不会覆盖新草稿。切换视图前排空写入队列，保存和导出使用同一版本。未修改源码时保留正文编辑器和撤销历史；实际修改源码后重新解析正文，未知结构继续保留并禁用不安全的可视化回写。

WritingToolbar 使用“开始 / 插入 / 布局”和图片/表格上下文标签，工具始终只占一行；文件与三视图切换占另一行。普通窗口下总高度 94 px。白蓝主题只改变界面，不重写已有文稿中的自定义颜色。

core/word-count.ts 遍历正文富文本，包含标题和表格单元格；排除公式、图片、TeX 命令与注释。中日韩字符逐字计数，其他语言按词计数，英文连字符、撇号与数字小数保留为一个词。字符数按 Unicode 码点计算，段落分隔不计作字符。底部实时显示总量及选区量，可打开三个字数/字符数指标。源码无法解析时不提供猜测数值。

## 查找与替换

SearchPanel 是写作和源码视图共用的浮动面板，Ctrl+F / Ctrl+H 打开，Esc 关闭；关闭时不占布局空间。纯文本查找支持大小写选项，正则特殊字符按字面匹配，位置采用编辑引擎的 UTF-16 偏移。匹配高亮是只读装饰，不进入源码和撤销历史。

WritingSearch 在每个文本块中连接相邻文字节点，允许跨字体样式匹配，但不跨行内公式、硬换行或表格单元格。替换从后向前写入同一事务，保留段落结构与起点字符格式；全部替换为独立撤销步骤。源码使用相同面板和独立 CodeMirror 适配器，仅搜索当前文件；替换前后排空源文件队列，避免和前一段键入合并成一次撤销。只读文件禁止替换。

字数和文档标题按文档状态缓存，光标移动不重复序列化整篇正文。PDF.js 只在 PDF 视图中创建页面画布，写作和源码视图不绘制隐藏 PDF。LaTeX 编译继续在后台进行，不阻塞编辑输入。默认教程和 Windows 图标均采用白蓝配色，标题区域显示正文标题而非项目文件夹名称。
